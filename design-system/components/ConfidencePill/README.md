# ConfidencePill

The claim label on every news item: Announced, Reported, Verified on ground or Disputed.

Pass `label`. Each state carries its own shape (hollow circle, half circle, check, triangle) and word as well as its colour, so it reads without colour.

- Do show one on every news item and timeline entry.
- Don't re-label 'Verified' unless a field check happened.

Hand-written from `ConfidencePill` in apps/web/components/Score.tsx (emoji dots replaced by shape glyphs).
