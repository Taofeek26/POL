# Banner

A quiet green-tint notice strip for build status, method changes and corrections.

Children are the message; lead with a bold word (`Test build.`, `Correction.`). Green-tint ground, ink text.

- Do use it for corrections in public (blueprint principle 5).
- Don't use it for errors in a form: that is `Field`'s `error`.

Hand-written from the `.banner` in apps/web/app/layout.tsx.
