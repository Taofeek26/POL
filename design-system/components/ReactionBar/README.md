# ReactionBar

The five reactions on a news item: 👍, 👎, Impactful, Disputed, Show evidence, each with its count.

Pass `counts` and `mine` (the user's reactions); `onToggle(type, on)` reports a change. Selected reactions use the pressed button state. Disputed and Show evidence turn readers into fact-checkers: keep both.

Hand-written from apps/web/components/ReactionBar.tsx (API calls left to the app).
